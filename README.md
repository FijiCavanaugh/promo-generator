# promo-generator

Генератор промокодов для акций. Одна HTML-страница без зависимостей: открывается двойным кликом.

## Что умеет

- **Тематические коды** под акцию (реактивация, приветственный, VIP, Хэллоуин, Новый год, кешбэк, фриспины, депозит) на испанском, английском или на обоих языках. Примеры: `VUELVE150`, `BACK2WIN`, `VIPBONUS`.
- **Пакет уникальных кодов** со своим префиксом, например `VIP-K7M2QX`. Можно убрать похожие символы (0, O, 1, I, L).
- **Список использованных кодов**: такие коды в результат не попадут.
- Копирование одного кода или всех сразу, избранное.

Коды состоят только из A–Z и 0–9. Число 150000 автоматически превращается в `150K`. Избранное и список использованных хранятся в `localStorage` браузера.

## Запуск

Открой `index.html` в браузере. Для публикации можно включить GitHub Pages (Settings → Pages → ветка `main`).
